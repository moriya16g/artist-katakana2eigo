# artist-katakana2eigo

カタカナ表記の海外アーティスト名から、英語表記を調べるWebアプリです。
Apple Music日本版でカタカナになっているアーティスト名を、英語表記に置き換えるための置換ルール（JSON）を作れます。

**使う:** https://moriya16g.github.io/artist-katakana2eigo/

## できること

- カタカナのアーティスト名のリストを入れると、Apple Musicのデータから英語表記を取得します
- 表記が完全に一致したものと、近い候補しか見つからなかったものを分けて表示します
- 英語表記はその場で手直しできます
- チェックを入れたものを、置換ルールのJSONとしてコピー・保存できます

スマートフォンのブラウザで使うことを想定しています。インストールやサーバーは不要です。

## 使い方

1. アーティスト名を1行に1つずつ入力するか、テキストファイルを読み込みます。重複した行やカタカナを含まない行は自動で除かれるので、ライブラリの曲ごとのアーティスト一覧をそのまま入れても構いません。
2. 「変換を開始」を押します。1件あたり約3秒かかります。
3. 結果を確かめます。「要確認」で絞り込むと、候補止まりのものや見つからなかったものだけを見られます。
4. 「コピー」または「JSONを保存」で置換ルールを書き出します。

### ライブラリからアーティスト一覧を取り出す（iPhone / iPad）

ショートカットアプリで次のアクションを順に並べて実行すると、ライブラリ全曲のアーティスト名をテキストファイルにできます。

1. ミュージックを検索（条件・上限なし）
2. ミュージックの詳細を取得（アーティスト）
3. テキストを結合（改行）
4. ファイルを保存

## 出力形式

`origArtist` に一致するアーティスト名を `artist` に置き換えるルールを、配列で出力します。

```json
[
    {
        "hasOrigTrack": false,
        "origTrack": "",
        "hasOrigArtist": true,
        "origArtist": "ザ・ローリング・ストーンズ",
        "hasOrigAlbum": false,
        "origAlbum": "",
        "hasOrigAlbumArtist": false,
        "origAlbumArtist": "",
        "artist": "The Rolling Stones",
        "continueMatching": true
    }
]
```

既存の設定に追加するときは、外側の `[ ]` を外して貼り付けてください。

## しくみ

AppleのiTunes Search APIを2段階で使います。

1. 日本のストア（`country=jp`）を日本語（`lang=ja_jp`）でカタカナ名のまま検索し、アーティストIDを特定します。
2. 見つかったIDを英語（`lang=en_us`）で引き直し、同じアーティストの英語表記を取得します。

英語表記は推測や機械的な変換ではなく、Appleが持っている表記そのものです。
APIはブラウザから直接JSONPで呼び出していて、このアプリ側のサーバーはありません。

## 注意点

- **時間がかかる:** iTunes Search APIには1分あたり約20回の目安の制限があるため、リクエストの間隔を空けています。100件でおよそ5〜6分です。実行中は画面を開いたままにしてください。
- **邦楽アーティストも変換される:** カタカナ名の邦楽アーティストにもAppleの英語表記があれば、一致として扱われます。不要なものはチェックを外してください。
- **複数アーティスト表記:** 「A & B」のような連名は1人のアーティストとして見つからないことが多いので、手入力してください。
- **データの保存先:** 調べた結果と手で直した表記は、ブラウザのlocalStorageにだけ保存されます。次回同じ名前は再検索しません。消したいときは、ページ下部の「保存した結果を消去」を使ってください。

## 公開方法（GitHub Pages）

1. このリポジトリに `index.html` を置きます。
2. Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/artist-katakana2eigo/` で開けるようになります。
